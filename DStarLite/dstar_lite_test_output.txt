KEY D* LITE CONCEPTS:
────────────────────────────────────────────────────────────
  • g(s): Cost from goal to s (computed)
  • rhs(s): One-step lookahead cost (rhs(s) = min over neighbors)
  • Vertex is 'consistent' when g(s) == rhs(s)
  • Priority queue orders vertices by key = (min(g,rhs) + h + km, min(g,rhs))
  • Algorithm processes inconsistent vertices until start is consistent
